CORE CHECKLISTS

Routine, deep clean and property transition work

Use dedicated checklist sections for standard cleaning, kitchen, bathroom, bedroom and living areas, deep cleaning, and move-in / move-out work.

The Master Checklist provides an editable task library so wording and standards can be adapted to the agreed service scope.

Internal quality-control review

The Quality Control Signoff is designed for internal service-quality review, including job information, review result, notes/issues, follow-up and signatures/initials.

It is not a regulatory inspection, certification, legal audit or compliance system.

KNOW BEFORE YOU BUY

Compatibility and product boundaries

  • Microsoft Excel Desktop is the primary intended workbook environment.
  • Other spreadsheet software may display validation, formatting or print layouts differently.
  • The workbook is manual and contains no VBA or macros.
  • No CRM, calendar sync, automatic reminders, invoicing or payroll features are included.
  • The Example workbook contains fictional entries showing intended use.
  • The printable pack is A4.

Simple workflow

  1. Keep one untouched master copy of the Template workbook.
  2. Complete Setup for the job.
  3. Choose the checklist that matches the agreed service scope.
  4. Edit task wording or rows as needed.
  5. Record Done / N/A and flag Issue or Follow-up where applicable.
  6. Complete Quality Control Signoff when an internal review is needed.
  7. Use the A4 Printable PDF when paper is more practical.
