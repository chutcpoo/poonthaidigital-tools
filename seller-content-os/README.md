# Seller Content OS — Phase 8

Thai-first prototype for product-content generation, Product Fact Checker, Media QC, authorized marketplace import, and platform-specific policy prechecks.

## Deployment

- `index.html` is a lightweight loader.
- `app.dat` contains the verified Phase 8 single-file app compressed with gzip and is decompressed locally in modern browsers.
- No paid AI API is required for this build.
- No automatic social posting is enabled.

## QC status

Phase 8 regression scope previously tested: 75 PASS / 0 FAIL. This does **not** mean platform policy approval. Semantic media checks are preliminary and do not replace human review, OCR/audio-rights checks, or official platform moderation.
