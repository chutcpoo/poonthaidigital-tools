Privacy

This page explains the basic data practices for the PoonthaiDigital Tools website.

Calculator inputs

The current calculators run in your browser. Values entered into calculator fields are used to produce the on-page result and are not intentionally included in our analytics events.

Analytics

We use Vercel Web Analytics to understand page visits. We also record limited first-party events such as which free tool was used and when a visitor clicks a link to a PoonthaiDigital Etsy product. Those application events are designed to contain the tool or product identifier and page path, not the calculator values you entered.

Hosting and technical logs

The website is hosted by Vercel. Like most hosting providers, Vercel may process technical request information needed to deliver, secure and operate the site. Their practices are governed by their own terms and privacy documentation.

External links

Links to Etsy open an external website. Once you leave PoonthaiDigital.com, Etsy's own privacy and data practices apply.

Accounts and email

The current free tools do not require a PoonthaiDigital account or email signup.

Changes

We may update this notice when website features or analytics change. Last updated: September 16, 2026.
